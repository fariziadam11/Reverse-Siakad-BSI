# Sesi e-learning

Pemeriksaan 26 Oktober 2026 terhadap kode Android dan GET publik `https://elearning.bsi.ac.id/login`. Tidak ada kredensial, nilai cookie, CSRF atau CAPTCHA akun asli dalam catatan ini.

- Respons login publik mengirim `mybest_session` dan `XSRF-TOKEN` dengan `Max-Age=2700`, yaitu 45 menit. Ini adalah masa berlaku cookie yang diamati, bukan bukti batas sesi akun setelah login atau konfigurasi idle timeout server. Server dapat menolak sesi sebelum cookie kedaluwarsa.
- `BsiClient` mempertahankan cookie hasil setiap respons dan redirect. `AndroidSessionCookies` menunggu penyimpanan cookie selesai lalu melakukan `flush()`. Membuka ulang aplikasi memeriksa dashboard dengan cookie yang tersimpan; tidak ada timer logout lokal dalam alur yang diperiksa.
- Sebelumnya semua HTTP 419 dianggap sebagai logout. Token form lama dapat ditolak sementara autentikasi masih valid. Kini HTTP 419 memicu satu GET dashboard: dashboard mahasiswa yang valid mempertahankan sesi dan meminta pengguna memuat ulang form; halaman login atau 401/419 saat pemeriksaan memerlukan login kembali. Kegagalan jaringan saat pemeriksaan tidak diperlakukan sebagai bukti logout. Permintaan perubahan tidak pernah diulang otomatis.
- Logout lokal sebelumnya memakai `removeAllCookies()`, yang juga menghapus sesi layanan lain. Penghapusan kini hanya mengenai cookie root pada origin portal yang dipilih; e-learning dan Student V2 memakai origin berbeda. Cookie BSI yang diamati menggunakan `Path=/`.

Penyimpanan cookie memperbaiki kehilangan sesi di perangkat; ia tidak dapat memperpanjang sesi yang sudah dicabut server. CAPTCHA baru tetap mengikuti permintaan server. Penyebab server-side seperti invalidasi sesi, kebijakan akun atau batas idle belum dibuktikan. Masa berlaku 45 menit tidak boleh disebut sebagai penyebab tunggal keluhan tanpa pengukuran sesi autentikasi yang berkelanjutan.

Port Student V2 kemudian menemukan dan menguji jalur SSO resmi: Student `/mahasiswa/myLMS` mengirim token opaque ke MyBest `/authenticate-student`. Ini berhasil menghasilkan dashboard MyBest tanpa CAPTCHA melalui HTTP serta dari Android. Aplikasi mencoba jalur ini ketika sesi MyBest habis dan Student masih aktif. Cookie kedua origin tetap terpisah, token SSO tidak disimpan, dan kiriman sebelumnya tidak diulang. Jika kedua sesi berakhir, pengguna perlu login. Logout MyBest yang disengaja tidak memicu login SSO otomatis pada pembukaan berikutnya.

Verifikasi lokal: delapan `BsiClientSimulationTest` melewati HTTP asli ke simulasi Postman pada port 4914, seluruhnya lulus tanpa skip. Dua regresi membuktikan token basi tidak menghilangkan login dan POST yang ditolak hanya dikirim sekali. Collection `Android Session Checks` lulus delapan request dan delapan assertion. `SessionCookieIsolationTest` lulus pada emulator Android: penghapusan cookie portal pertama tidak menghapus cookie portal kedua; test hanya memakai host `.invalid`. Simulasi memakai fixture sintetis dan tidak membuktikan perilaku error BSI produksi. Kedua spesifikasi lulus lint sintaks Postman; lint governance membutuhkan login CLI.
